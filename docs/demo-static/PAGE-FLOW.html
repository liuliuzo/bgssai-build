bgssai-build 页面状态流转图与交互矩阵

规范 Cursor GUI 视窗、Grok-Build 终端 TUI 视窗与 Docmost 实时研发同步之间的状态跃迁与触发机制。

一、端到端研发透明化闭环 (Core User Journey)
1
发起需求或架构任务
用户在 agents-window.html 居中 Composer 输入提示词，选择 Tokenhub 目标模型（如 Claude 3.7 或 DeepSeek-R1），或者按下 Shift+Tab 进入 agent-plan.html 进行多阶段需求拆解。
2
自动创建 Docmost 空间与 PRD/HLD 说明书
Agent 通过 bgssai-docmost MCP 自动在目标文档库创建对应空间及文档页面，生成软件工程标准说明书（需求说明、概要设计、技术选型）。
3
实时执行、推演与 UML 流式同步
在 agents-chat.html 中，用户可看到工具调用追踪流（Tool Calling）。与此同时，Agent 将生成的 6 类 Mermaid UML 图表（类图、时序图、泳道图等）直接写入 docmost-sync.html，完全杜绝黑盒编程。
4
双轨审核 (Diff Review + 架构图核验)
代码执行完成后跳转至 agent-review.html。左侧呈现代码行级 Diff，右侧呈现 Docmost 最新的 UML 类图与接口状态。用户确认无误后点击「批准并合并至 develop」。
5
无缝切入 TUI 终端模式
在任何时刻点击快捷键 F9 或点击顶栏，即可瞬时切入 tui-terminal.html，在纯键盘终端环境下体验 Grok-Build 风格的轻量高速 TUI 流式推演。
二、页面跳转与状态触发矩阵 (Routing Matrix)
起始页面 (Source) 用户操作 / 触发事件 目标页面 (Target) 交互说明与数据传递
agents-window.html 回车提交 Prompt agents-chat.html 携带 prompt 与 model_id，开启 Agent 推演流并在后台激活 Docmost MCP 同步通道
agents-window.html 点击 Plan 或 Shift+Tab agent-plan.html 切换到多阶段工程拆解模式，生成 PRD 需求文档与流程图
agents-chat.html 代码生成完成 / 点击 Files Changed agent-review.html 载入 git diff 树与对应的 Docmost 架构类图进行双轨对照核验
agents-chat.html / 全局 点击 Docmost 同步胶囊 docmost-sync.html 打开知识库全屏实时同步看板，查看 PRD/HLD/LLD 及 6 类 UML 图表
全局 (任意视窗) 点击右上角 IDE 视图 ↗ editor-agent.html 进入经典深色 VS Code 布局，左侧目录树与代码区，右侧 Agent 对话辅助
全局 (任意视窗) 点击左侧菜单「配置 & 扩展」 mcp.html 管理 MCP 工具协议，可进一步切换至 Skills、Rules、Tokenhub 设置
全局 (任意视窗) 点击左侧菜单「TUI 终端」或按 F9 tui-terminal.html 切入 Grok-Build Rust Ratatui 终端模式，全键盘操作与流式输出
agent-review.html 点击「批准并合并到 develop」 agents-window.html 执行 git merge，自动在 Docmost 归档版本 Snapshot，回到准备就绪状态
