bgssai-build UI 原型规范画廊
进入 Agents 独立窗口 进入 IDE 协同视图 Docmost 同步中心 查看页面流转图

核心设计理念：融合 Cursor 交互 + Grok-Build 终端 + Docmost 研发透明化

本项目对标 Cursor 的现代独立 Agents 窗口（居中 Composer、多阶段 Plan、高保真 Diff Review、Customize 规则与技能体系）与 Grok-Build 的高性能 Rust Ratatui 终端模式；
同时彻底解决 Agent 编程「黑盒失控、用户无法洞察设计细节」的业界通病——通过注入 MCP 实时同步协议，在编码推演过程中持续将 PRD 需求、HLD 概要设计、LLD 详细设计以及 6 类 Mermaid UML 图表（类图、时序图、泳道图、状态图、流程图、架构图） 实时流式写入 bgssai-docmost。

1. Agents 独立视窗系统 (Cursor 对齐) 现代居中布局 · 多模式协同
轻量独立的沉浸式 AI 编程交互视窗，具备强大的上下文感知与模型路由。
Agents 主窗口 (Home) 居中 Composer · Tokenhub 模型选择 · Docmost 连通胶囊
Agents 对话执行态 (Chat & Traces) 思考流 · 工具追踪 · 嵌入式 UML 时序图 · 代码变更卡
Plan 规划模式 (Plan Mode) 多阶段拆解 · 自动化 PRD 撰写 · 实时流程图推演
Review 审查模式 (Diff Review) 双轨校验 · 代码行级 Diff 审查 · UML 架构一致性核验
2. 经典 IDE 编辑器双核模式 (VS Code 风格) Activity Bar · 代码高亮 · 侧边 Assistant
供习惯传统开发环境的工程师在代码工作区与 Agent 之间无缝切换。
IDE + Agent 协同视窗 深色经典编辑环境 · 目录树 · Monaco Diff 高亮 · 侧栏 Agent
3. 研发透明化同步中心 (bgssai-docmost Killer Feature) 消灭黑盒 · 6 类 UML 实时镜像
解决 AI 编程用户完全无法知道做了什么的痛点，所有架构推演与软件工程文档自动上屏。
